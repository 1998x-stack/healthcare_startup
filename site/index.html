Overview · 项目概述

两条主线：数据采集 + 智能问答

Python 数据采集（爬虫）

三个爬虫（医院 / 药品 / 医患问答）统一为工厂模式：ScraperFactory.create(site) 返回绑定解析器的具体 Scraper，共享一条多进程流水线。

已修复旧代码中 cannot pickle “_thread.lock” 的多进程崩溃。

ChatGPT 医疗小程序

微信小程序 MedGPT/：注册登录、问题输入与选择、对话、医院 / 医生推荐、档案管理； 云函数接入 ChatGPT 回答用户问题并给出推荐策略。

平台思维

以患者信息档案为核心建立护城河，体检报告解读 + 数据飞轮为 P0，打造数据驱动的医疗服务入口。

Architecture · 技术架构

工厂模式的爬虫架构

用一个 BaseScraper 承载共享流水线与多进程编排，字段抽取委托给站点无关的 Parser —— 新增数据站点只需注册一个新解析器。

scrapers/ 包

base.py BaseScraper（流水线 + JoinableQueue 多进程）
parsers.py Hospital / Medicine / QA 解析器 + 注册表
scrapers.py 三种具体 Scraper
factory.py ScraperFactory.create(site)
urls.py URL 构建

共享流水线

build_tasks() → (key, url) → 模块级 worker 跨进程多线程 → 聚合保存 <site>.json。 解析器通过注入的 fetch() 访问子页，测试全程离线。
